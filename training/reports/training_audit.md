## Fixes made during the audit
- Notebook cell 6 passed `--resume` without `--run-id`, so a resumed session would have started a NEW run directory.
  Added a `RUN_ID` form field and `--run-id RUN_ID`.
- On resume the runner rebuilt the dataset every session (built files are gitignored → full source download + ~45 min).
  A resumed run now reuses its own dataset on Drive when every file matches its manifest (tampered → rebuilt).
