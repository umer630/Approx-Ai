## Blockers

- **Human review.** 0 records are human-reviewed. No reviewer has used `datahub review-sheet` / `review-import` yet. The `human_review` gate fails for every model and cannot be passed without real reviewers.
- **Base-model license (Nick 4.8).** `Qwen/Qwen2.5-3B-Instruct` is released under the `qwen-research` license (Hub card), which does not grant commercial use. Commercial alternatives verified on the Hub: `Qwen/Qwen2.5-1.5B-Instruct` (Apache-2.0), `Qwen/Qwen2.5-7B-Instruct` (Apache-2.0), `microsoft/Phi-3.5-mini-instruct` (MIT), `HuggingFaceTB/SmolLM2-1.7B-Instruct` (Apache-2.0). The base model was NOT changed: switching it means a new model version and a full retrain, which is your decision.
- **FAB 100X base model.** `fab-100x` has no base model in its profile. Training is blocked until a base model (and license) is chosen.
- **Unavailable source.** Hendrycks MATH (`competition-math`) returns HTTP 400 from the Hub (taken down). Mathematics relies on GSM8K + curriculum.
- **Sources awaiting license review.** SlimOrca, MetaMathQA, Orca-Math, Magicoder-OSS, CodeAlpaca (OpenAI-generated outputs, terms restrict competing models), HelpSteer2 (ShareGPT-derived prompts), Tulu-3-SFT (mixed per-subset licenses). Not ingested.
- **Rejected sources.** SciQ, Alpaca, No Robots (non-commercial licenses); OpenHermes-2.5, SmolTalk (no declared license).
- **Language and domain gaps.** The approved-source pool is short of Urdu (823 records), Korean (286), Roman Urdu (559), Hindi (839) and Indonesian (757), and of software_engineering (200), cybersecurity (240), web_backend (125) and safety_ethics records. Closing these needs new licensed sources or human-authored data, not duplication.
- **Consented history.** `no_missing_sources` fails because `data/consented/latest.jsonl` (opt-in user history, Nick/Hike/Sona only) does not exist. No consented user data exists yet; FAB never uses it.
- **Known issue.** Some Aya ISO-639-3 codes are not mapped to ISO-639-1 (e.g. `eus`/`eu`, `fin`/`fi`, `hun`/`hu`, `swe`), so a few small languages appear under two codes. None of the 17 target languages is affected.
- **Not verified here.** GPU training, `tests/test_recovery.py` and the 4 torch-dependent tests in `test_colab_pipeline` need torch/GPU and were not run in this environment.
